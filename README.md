# 2026 사회복지사 급여 시뮬레이터

> 서울시 사회복지사를 위한 2026년 급여 계산 및 예상 도구

## 📋 개요

이 애플리케이션은 서울시 사회복지시설 종사자들의 2026년 급여를 정확하게 계산하고 예상할 수 있도록 설계된 웹 기반 급여 시뮬레이터입니다. 사용자는 직급, 호봉, 가족 상황 등을 입력하여 월별 및 연간 급여를 상세히 확인할 수 있습니다.

---

## ✨ 주요 기능

### 1. 급여 계산기 (메인 화면)
- **직급/호봉 선택**: 1급~기능직까지 7개 직급, 호봉별 기본급 자동 조회
- **가족수당 계산**: 배우자, 자녀(첫째/둘째/셋째 이상), 기타 부양가족 각각 별도 입력
- **만 6세 이하 자녀 비과세**: 자녀별 만 6세 이하 여부 체크 시 비과세 혜택 자동 적용 (월 최대 20만원)
- **관리자 수당**: 관리직 여부에 따른 관리자수당 자동 반영
- **승급월 설정**: 연중 호봉 승급 시점 선택 가능

### 2. 추가 수당 설정
- **법인 수당**: 월별 또는 연간 단위로 입력 가능
- **자치구 추가 혜택**: 
  - 유형 선택: 없음 / 복지포인트 / 수당
  - 복지포인트: 연간 총액 입력 시 6월/12월 분할 지급
  - 수당: 월별 또는 연간 지급 주기 선택 가능

### 3. 명절휴가비 설정
- 기본: 2월, 9월 (설날, 추석)
- 지급월 커스터마이징 가능 (클릭으로 토글)

### 4. 급여 결과 표시
- **월 예상 급여**: 기본급, 식대, 가족수당, 각종 수당 상세 표시
- **총 공제액**: 국민연금, 건강보험, 장기요양, 고용보험, 소득세, 지방소득세
- **실수령액**: 총 급여에서 공제액을 뺀 실제 수령액
- **선택적 공제**: 식대 공제(급식비), 상조회비 등 추가 공제 항목 직접 입력

### 5. 연봉 예상액
- **12개월 급여 합계**: 월급 × 12개월
- **명절휴가비**: 기본급의 60% × 2회 = 120%
- **서울시 복지포인트**: 호봉에 따라 30만원 또는 40만원
- **자치구 추가 혜택**: 설정된 자치구 수당/복지포인트 합계
- **2025년 대비 증감률**: 각 항목별 전년 대비 변화율 표시 (YoY 비교)

### 6. 월별 상세 명세 (연간 리포트)
- 12개월 전체 급여 명세 테이블 표시
- 승급월 반영: 승급 시점 이후 호봉 자동 증가
- 명절휴가비 지급월 하이라이트
- 서울시 복지포인트 (6월/12월 지급) 표시
- 선택적 공제 항목 반영
- **모바일 최적화**: 데스크톱에서는 테이블, 모바일에서는 카드 형식 표시

### 7. 월별 상세 시뮬레이션 모달
- 특정 월 클릭 시 상세 시뮬레이션 모달 표시
- 시간외근무수당 직접 입력 가능
- 해당 월의 모든 수당 및 공제 상세 확인

### 8. PDF/CSV 내보내기
- **CSV 다운로드**: 12개월 급여 데이터를 엑셀 호환 CSV로 다운로드
- **PDF 내보내기**: A4 가로 방향 단일 페이지 PDF 생성
  - 크로스 브라우저 호환 (Mac/Windows)
  - 프린트 스타일 최적화

## 🔢 2026년 급여 기준

### 공제율
| 항목 | 2025년 | 2026년 |
|------|--------|--------|
| 국민연금 | 4.5% | **4.75%** |
| 건강보험 | 3.545% | **3.595%** |
| 장기요양보험 | 건강보험의 12.95% | **건강보험의 13.14%** |
| 고용보험 | 0.9% | 0.9% |

### 수당 기준
| 항목 | 2025년 | 2026년 |
|------|--------|--------|
| 식대 | 130,000원 | **140,000원** (+10,000원) |
| 관리자수당 | 200,000원 | **220,000원** (+20,000원) |
| 복지포인트 (10호봉 이상) | 400,000원 | 400,000원 |
| 복지포인트 (10호봉 미만) | 300,000원 | 300,000원 |

### 가족수당
| 구분 | 금액 |
|------|------|
| 배우자 | 40,000원 |
| 첫째 자녀 | 50,000원 |
| 둘째 자녀 | 80,000원 |
| 셋째 이상 자녀 (1인당) | 120,000원 |
| 기타 부양가족 (1인당) | 20,000원 |

- 4대 보험 및 세금 공제 계산

- 자녀별 상세 입력 (첫째/둘째/셋째 이상 구분)

- 승급월 반영 기능
- CSV 다운로드 기능

- 모바일 최적화 (카드 뷰)

- A4 가로 단일 페이지 PDF 생성
