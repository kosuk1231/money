## 1. 시작하기

### 1.1 접속 방법
웹 브라우저에서 애플리케이션 URL에 접속합니다.

### 1.2 화면 구성
- **왼쪽 패널**: 입력 폼 (직급, 호봉, 가족 정보 등)
- **오른쪽 패널**: 결과 표시 (월 급여, 연봉 예상액)
- **하단**: 연간 리포트 테이블

---

## 2. 기본 정보 입력

### 2.1 직급 선택
드롭다운 메뉴에서 본인의 직급을 선택합니다.

| 직급 | 대상 |
|------|------|
| 1급 | 관장, 원장 (10인 이상 15년 이상) |
| 2급 | 관장, 원장 (10인 이상 11~15년) / 부장 (15년~) |
| 3급 | 관장, 원장 (10인 미만 15년 미만) / 과장 |
| 4급 | 대리 / 선임생활지도원 |
| 5급 | 사회복지사, 간호사 등 |
| 관리직 | 간호조무사, 사무원 등 |
| 기능직 | 생활보조원, 조리원, 관리인 등 |

### 2.2 호봉 선택
드롭다운 메뉴에서 본인의 호봉을 선택합니다.
- 호봉은 근무 연수에 따라 결정됩니다.
- 1급은 16호봉부터 시작합니다.

### 2.3 관리자 여부
관리자직(시설장, 부장 등)인 경우 체크박스를 선택합니다.
- 선택 시 관리자수당 **220,000원**이 추가됩니다.

### 2.4 승급월 설정
연중 호봉이 올라가는 시점을 선택합니다.
- 예: 3월에 승급하면 "3월" 선택
- 승급 없으면 "없음" 선택
- 승급월 이후부터 다음 호봉의 기본급이 적용됩니다.

## 3. 가족 정보 입력

### 3.1 배우자
배우자가 있는 경우 체크박스를 선택합니다.
- 가족수당 **40,000원** 추가

### 3.2 자녀 정보

#### 첫째 자녀
- "첫째 자녀" 체크: 가족수당 **50,000원** 추가
- "만 6세 이하" 체크: 해당 금액 비과세 처리

#### 둘째 자녀
- "둘째 자녀" 체크: 가족수당 **80,000원** 추가
- "만 6세 이하" 체크: 해당 금액 비과세 처리

#### 셋째 이상 자녀
- 숫자 입력: 셋째 이상 자녀 수 (1인당 **120,000원**)
- "만 6세 이하" 체크: 해당 자녀 수만큼 비과세 처리

> **💡 팁**: 만 6세 이하 자녀의 가족수당은 월 최대 **200,000원**까지 비과세됩니다.

### 3.3 기타 부양가족
부모님 등 기타 부양가족 수를 입력합니다.
- 1인당 가족수당 **20,000원** 추가

---

## 4. 추가 수당 설정

### 4.1 법인 수당
소속 법인에서 지급하는 추가 수당을 입력합니다.

| 옵션 | 설명 |
|------|------|
| 월별 | 매월 지급되는 금액 입력 |
| 연간 | 연간 총액 입력 (12로 나눠 월 표시) |

### 4.2 자치구 추가 혜택
소속 자치구에서 지급하는 추가 혜택을 설정합니다.

#### 유형 선택
- **없음**: 추가 혜택 없음
- **복지포인트**: 자치구 복지포인트 (6월/12월 분할 지급)
- **수당**: 자치구 추가 수당

#### 복지포인트 설정
- 금액: 연간 총액 입력
- 6월과 12월에 절반씩 분할 지급
- 전액 비과세 처리

#### 수당 설정
- 금액: 수당 금액 입력
- 지급 주기: 월별 또는 연간 선택

### 4.3 명절휴가비 지급월
명절휴가비가 지급되는 월을 커스터마이징합니다.
- 기본값: 2월(설), 9월(추석)
- 월 버튼을 클릭하여 추가/제거
- 명절휴가비 = 기본급 × 60%

## 5. 급여 결과 확인

### 5.1 월 예상 급여

#### 지급 항목
| 항목 | 설명 |
|------|------|
| 기본급 | 직급/호봉에 따른 기본 급여 |
| 식대 | 140,000원 (비과세) |
| 관리자수당 | 220,000원 (해당 시) |
| 가족수당 | 가족 구성에 따라 계산 |
| 통상임금 | 기본급 + 식대 + (기본급 × 10%) |

#### 공제 항목
| 항목 | 계산 방법 |
|------|----------|
| 국민연금 | 과세소득 × 4.75% |
| 건강보험 | 과세소득 × 3.595% |
| 장기요양 | 건강보험 × 13.14% |
| 고용보험 | 과세소득 × 0.9% |
| 소득세 | 간이세액표 기준 |
| 지방소득세 | 소득세 × 10% |

#### 선택적 공제
직접 입력하는 추가 공제 항목입니다.
- **식대 공제(급식비)**: 기관 급식 이용 시 공제되는 금액
- **상조회비**: 상조회 가입 시 공제되는 금액

> **⚠️ 주의**: 선택적 공제는 공제액에 포함되어 실수령액에서 차감됩니다.

### 5.2 연봉 예상액
연간 총 급여 예상액을 확인합니다.

| 항목 | 설명 |
|------|------|
| 12개월 급여 | 월급 × 12개월 |
| 명절휴가비 | 기본급 × 60% × 지급 횟수 |
| 서울시 복지포인트 | 300,000원 또는 400,000원 |
| 자치구 추가 혜택 | 설정한 금액 |
| **연간 총액** | 위 항목 합계 |

#### YoY 비교
각 항목 옆에 2025년 대비 변화율이 표시됩니다.
- 🟢 **+X.X%**: 2025년 대비 증가
- 🔴 **-X.X%**: 2025년 대비 감소

## 6. 연간 리포트 활용

### 6.1 테이블 보기 (데스크톱)
12개월 전체 급여 명세를 테이블 형식으로 확인합니다.

| 열 | 설명 |
|-----|------|
| 월 | 1월~12월 |
| 호봉 | 해당 월의 호봉 (승급 반영) |
| 기본급 | 호봉에 따른 기본급 |
| 식대 | 140,000원 |
| 가족수당 | 가족 구성에 따른 금액 |
| 명절휴가비 | 지급월에만 표시 |
| 복지포인트 | 6월/12월에 표시 |
| 공제계 | 모든 공제 합계 |
| 실수령액 | 총 지급액 - 공제계 |

### 6.2 카드 보기 (모바일)
모바일에서는 각 월이 카드 형식으로 표시됩니다.

### 6.3 특수 표시
- 🔵 **승급월**: 호봉이 올라가는 월
- 🎉 **명절휴가비**: 명절휴가비 지급월
- ✨ **복지포인트**: 복지포인트 지급월

## 7. 월별 상세 시뮬레이션

### 7.1 모달 열기
연간 리포트에서 특정 월을 클릭하면 상세 시뮬레이션 모달이 열립니다.

### 7.2 시간외근무수당 입력
- 시간외근무 시간을 직접 입력할 수 있습니다.
- 통상임금을 기준으로 시간외근무수당이 자동 계산됩니다.

### 7.3 상세 내역 확인
해당 월의 모든 지급 항목과 공제 항목을 상세히 확인할 수 있습니다.

## 8. 데이터 내보내기

### 8.1 CSV 다운로드
1. 연간 리포트 상단의 **"CSV 다운로드"** 버튼 클릭
2. `2026_salary_report.csv` 파일이 다운로드됩니다.
3. Excel이나 Google Sheets에서 열 수 있습니다.

### 8.2 PDF 내보내기
1. 연간 리포트 상단의 **"PDF 내보내기"** 버튼 클릭
2. A4 가로 방향의 PDF가 생성됩니다.
3. 인쇄하거나 저장할 수 있습니다.

### 8.3 인쇄
1. **"인쇄"** 버튼을 클릭하거나 브라우저의 인쇄 기능 사용
2. 프린트 미리보기에서 확인 후 인쇄

## 9. 자주 묻는 질문

### Q1. 계산된 급여가 실제와 다릅니다.
**A**: 이 시뮬레이터는 서울시 인건비 가이드라인을 기준으로 합니다. 실제 급여는 소속 기관의 내부 규정에 따라 다를 수 있습니다.

### Q2. 세금 계산이 정확한가요?
**A**: 간이세액표를 기반으로 한 추정치입니다. 실제 세금은 연말정산 시 조정될 수 있습니다.

### Q3. 만 6세 이하 비과세는 어떻게 적용되나요?
**A**: 만 6세 이하 자녀의 가족수당은 월 최대 20만원까지 과세소득에서 제외됩니다. 이로 인해 4대보험과 세금이 줄어듭니다.

### Q4. 복지포인트는 왜 6월과 12월에만 표시되나요?
**A**: 서울시 복지포인트는 연 2회(6월, 12월) 분할 지급됩니다.

### Q5. 승급월 설정은 어떻게 작동하나요?
**A**: 설정한 월부터 호봉이 1단계 올라갑니다. 예를 들어 현재 5호봉이고 승급월을 3월로 설정하면, 1~2월은 5호봉, 3~12월은 6호봉 기본급이 적용됩니다.

### Q6. 자치구 복지포인트와 수당의 차이는?
**A**: 
- **복지포인트**: 비과세이며 6월/12월 분할 지급
- **수당**: 과세 대상이며 월별 또는 연간 지급

### Q7. 데이터는 저장되나요?
**A**: 아니요. 모든 계산은 브라우저에서 실시간으로 이루어지며, 서버에 저장되지 않습니다. 페이지를 새로고침하면 입력값이 초기화됩니다.
